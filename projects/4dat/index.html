Highlights

  • Set up the stack every app in the suite shares — Swift 6 strict concurrency, SwiftUI-only UI, @Observable MVVM, DI through the SwiftUI Environment, SwiftData.
  • Extracted a design system, an OCR pipeline and a photo viewer into reusable Swift packages, so each new app starts from working components.
  • Built a vision package with image preprocessing and a dedicated path for reading seven-segment device displays.
  • Kept business rules testable with a use-case layer between view models and persistence.
  • Shipped StoreKit 2 subscriptions and consent-gated AdMob banners (UMP + ATT) across the suite.

The problem

The client needed about ten related apps. Built separately, the apps would have drifted apart and each would have repeated the others’ bugs.

My approach

  • One stack for the whole family. iOS 18/26, Swift 6 strict concurrency, SwiftUI-only UI, @Observable MVVM, NavigationStack with NavigationPath, DI through the SwiftUI Environment, and SwiftData persistence.
  • Shared Swift packages. A design system, an OCR pipeline and a photo viewer. A new app started from working components instead of a copy of an old one.
  • Use-case layer. It sits between view models and persistence, so business rules are testable and don’t depend on SwiftUI.
  • Domain logic for each product. Blood-pressure classification is derived at display time instead of being stored. Home bills surface their due dates and can be marked as paid quickly. Vehicles have maintenance logs and service intervals.

Technical deep dive: the vision package

The package has two products:

  1. Preprocessing: orientation, grayscale, contrast, thresholding, denoising and scaling.
  2. Recognition: a generic OCR path, plus a dedicated path for seven-segment displays, which general-purpose OCR reads poorly.

Monetisation

A GoogleMobileAds banner is bridged into SwiftUI through UIViewRepresentable and anchored in the root view. An observable monetisation store makes every ad request wait for UMP consent and App Tracking Transparency. Subscriptions use StoreKit 2. I also handled App Store Connect setup and the releases for the whole suite.
